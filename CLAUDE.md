# Coach Dashboard

Client-facing web dashboard for coaches to monitor player health, performance, and team analytics from BLE wearable data.

## Tech Stack

- **Framework**: React 19 + TypeScript + Vite 8 (React Compiler enabled)
- **Package manager**: bun (standalone — NOT in pnpm monorepo workspace)
- **UI**: shadcn/ui (base-nova style) + Tailwind CSS v4
- **Routing**: TanStack Router (file-based, type-safe params)
- **Server state**: TanStack Query v5 + graphql-request (AppSync GraphQL)
- **Global state**: Zustand (auth store, UI store)
- **Forms**: React Hook Form + Zod validation
- **Charts**: Recharts
- **Icons**: Lucide React
- **Auth**: @aws-sdk/client-cognito-identity-provider (Cognito, coach role)

## Design System

- **Theme**: Dark mode only
- **Primary**: #E07800 (orange)
- **Backgrounds**: #121212 (bg) → #1D1D1D (surface) → #2A2A2A (surface-light) → #333333 (surface-lighter)
- **Typography**: Orbitron (headings, metric values), Inter (body, UI text)
- **Semantic colors**: success #4CAF50, warning #FFC107, error #FF4D4D, info #2196F3
- **Tailwind tokens**: Defined in `src/index.css` via `@theme` block
- **shadcn theme**: CSS variables remapped to Hyvia tokens in `index.css`

## Conventions

### Components
- Use arrow function syntax: `const MyComponent = () => { ... }`
- shadcn/ui components in `components/ui/` — generated via CLI, don't edit directly
- Shared components in `components/shared/` — reusable across features
- Feature-specific components live inside `features/{name}/`
- Page components are in route files (`routes/`)

### Data Fetching
- All API calls go through `lib/graphql.ts` (graphql-request + JWT from Zustand)
- Wrap in TanStack Query hooks in `features/{name}/api.ts`
- Query keys: `['feature', ...params]` (e.g., `['squad']`, `['player', playerId, 'hrv']`)
- Mutations: use `useMutation` — never store loading/error state in Zustand

### State Management
- **Server state** → TanStack Query (caching, refetch, loading/error via mutations)
- **Global client state** → Zustand stores (`stores/`)
- **Local UI state** → React useState/useReducer in components
- Never duplicate server state in Zustand

### Forms
- Use React Hook Form + Zod for all forms
- Validation schemas defined with Zod, resolved via `@hookform/resolvers`

### Routing
- File-based routes in `src/routes/`
- `_authenticated.tsx` layout provides auth guard via `beforeLoad`
- Type-safe params: `$playerId`, `$trainingId`, `$matchId`
- Route tree auto-generated by TanStack Router Vite plugin (`routeTree.gen.ts`)

### Auth
- AWS SDK v3 `@aws-sdk/client-cognito-identity-provider` (InitiateAuthCommand)
- Cognito User Pool (same pool as player app, different role)
- Coach role: `custom:role = "coach"`, `custom:club_id` for club scoping
- User attributes from JWT: `given_name`, `family_name`, `email`
- JWT stored in Zustand auth store, injected into GraphQL requests
- Session persisted via Zustand `persist` middleware
- Login mutation in `features/auth/api.ts` (useMutation)

## Backend API

- **Endpoint**: AWS AppSync GraphQL (env var `VITE_APPSYNC_URL`)
- **Auth**: JWT Bearer token in `Authorization` header
- **Key queries**: `getSquad`, player health data queries (coach-scoped)
- **Key mutations**: `invitePlayer`, `resendPlayerCode`
- **Schema reference**: `backend/graphql/schema/schema.graphql`
